# Machine Learning Fundamentals (Python)

This repository contains **implementations and experiments with core machine learning algorithms**, built to strengthen my understanding of how models work internally rather than relying only on libraries.

The focus is on **learning by implementation, comparison, and visualization**.

---



## 🧠 Algorithms Covered

- Linear Regression
- Multiple Linear Regression
- Gradient Descent
- K-Nearest Neighbors (KNN)
- Basic classification comparisons

Each algorithm includes:
- Python implementation
- Dataset used
- Output files (plots / text results where applicable)

---

## 📊 Outputs & Visualizations

Where applicable, results are saved as:
- **PNG images** for easy viewing
- **Text outputs** for numerical analysis

(Plots are generated using Matplotlib.)

---

## 🎯 Purpose of This Repository

- Understand ML algorithms beyond black-box usage
- Practice data preprocessing and evaluation
- Build intuition around model behavior and hyperparameters
- Maintain clean, reproducible experiments

This repository is **learning-focused**, not production-deployed.

---

## 🛠 Tech Stack

- Python
- NumPy
- Pandas
- Matplotlib
- scikit-learn (used only for validation/comparison)
